CARA_BERMAIN.EXE

CARA BERMAIN 30 HARI

  • 🎯 Tujuanmu: Bertahan hidup sebagai SysAdmin selama "30 Hari" tanpa membiarkan data server hancur.
  • 🪙 Kamu punya modal awal $1500. Pilih tipe RAID yang menurutmu paling efisien.
  • 💰 Setiap hari server menghasilkan uang: makin cepat tipe RAID-nya, makin besar penghasilannya (RAID 0 terbesar, RAID 1 terkecil).
  • ⚠️ BENCANA: Sewaktu-waktu, Hard Disk bisa terbakar secara acak! Semakin lama, risiko semakin besar.
  • 🧪 Untuk presentasi: matikan "Bencana acak" di Pengaturan, lalu pakai tombol Simulasikan Disk Rusak untuk memperagakan pemulihan data secara terkendali.
  • 💾 Backup: RAID bukan pengganti backup! Beli backup ($150) sebagai jaring pengaman: jika data hilang kamu dipulihkan (denda $200) dan game lanjut. Berlaku sekali.
  • 🎲 Kejadian acak: klien bonus, denda audit, atau ruang server panas (risiko disk rusak 2x).
Cara Menyelamatkan Data
  1. Saat disk rusak (merah), klik "Beli Pengganti ($100)".
  2. Setelah disk baru dipasang, klik tombol besar "Rebuild Data" di kiri bawah.
  3. Tunggu 3 detik. Jangan sampai disk lain rusak saat rebuild berlangsung!
⚠ Peringatan Kritis (Game Over jika)

RAID 0: Jika 1 disk saja rusak = LANGSUNG GAME OVER.

RAID 5: Hanya tahan 1 disk rusak. Jika 2 disk rusak bersamaan = GAME OVER.

RAID 1: 4 salinan identik. GAME OVER hanya jika keempat disk rusak.

RAID 10: 2 pasang mirror. GAME OVER jika kedua disk dalam satu pasangan (Disk 1+2 atau Disk 3+4) rusak.

Kamu kehabisan uang dan tidak bisa membeli disk pengganti ($100)!
